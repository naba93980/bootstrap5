# Bootstrap 5

A collection of Bootstrap 5 examples, practice exercises and its approach to responsive web development.

## About

This repository contains practice code for understanding how Bootstrap's CSS framework and built-in components help create responsive, consistent, and mobile-friendly web interfaces.

## Topics Explored

- **Getting Started with Bootstrap 5** — setup and framework integration
- **Grid System** — containers, rows, columns, and responsive layouts
- **Responsive Design** — breakpoints and responsive utility classes
- **Typography and Colors** — text styling and contextual color utilities
- **Spacing Utilities** — margins, padding, and sizing
- **Buttons and Components** — reusable interface elements
- **Navigation** — navbars, navigation links, and menus
- **Forms** — form controls and layout
- **Cards and Containers** — structuring page content
- **Flexbox Utilities** — alignment, ordering, and layout
- **Bootstrap JavaScript Components** — interactive components and behavior
- **Responsive UI Practice** — applying Bootstrap classes to build web layouts

*The listed topics are representative of Bootstrap 5 learning; the exact coverage depends on the examples in the repository.*

## Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code
- Basic knowledge of HTML and CSS

### Clone the Repository

```bash
git clone https://github.com/naba93980/bootstrap5.git
cd bootstrap5
```

Open the relevant HTML files in your browser to explore the examples. Depending on how Bootstrap is included, the examples may use a CDN or local project files.
